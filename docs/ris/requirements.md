# Requirements

## Core Requirements

- The node must run on commodity hardware
- Sensors are assumed to be partially untrusted
- Operators must retain explicit control over data exposure
- Remote access must be authenticated and authorized
- Data access must be observable and auditable

## Non-Functional Requirements

- Minimal operational complexity
- Clear failure modes
- Graceful degradation under load
- No mandatory external dependencies

## Deferred Requirements

- Automatic pricing or discovery
- Cross-node federation
- Global naming or routing
